# پل MCP منشی

با این پل، **هوش مصنوعیِ خودت دادهٔ منشی را می‌خواند** — و می‌تواند صورت‌جلسه هم برگرداند.

هیچ پورتی باز نمی‌شود و هیچ درخواستی به شبکه نمی‌رود. فقط دو فایل روی دیسکِ خودت:

```
manshi-data/
  snapshot.json   ← منشی می‌نویسد
  inbox.json      ← سرور می‌نویسد، منشی با تأیید تو اعمال می‌کند
```

> **این برای کاربر حرفه‌ای است.** به Node نیاز دارد و فقط با ابزارهای دسکتاپی کار می‌کند.
> اگر فقط می‌خواهی یک بار سؤالی بپرسی، در منشی دکمهٔ **«بپرس از AI»** را بزن — نصب نمی‌خواهد.

---

## راه‌اندازی

**۱. در منشی پوشه را بده.** تنظیمات ← پل هوش مصنوعی ← تیکِ snapshot، سطح را روی
**متن کامل** بگذار (وگرنه متنِ جلسه‌ها در فایل نیست و صورت‌جلسه‌سازی ممکن نمی‌شود)،
بعد **انتخاب پوشه**.

**۲. سرور را به ابزارت معرفی کن.** مسیرها را با مسیرِ خودت عوض کن.

Claude Code:

```bash
claude mcp add manshi -- node ~/Documents/manshi-suite/mcp/manshi-mcp.js --data ~/manshi-data
```

Claude Desktop — در `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "manshi": {
      "command": "node",
      "args": ["/Users/USER/Documents/manshi-suite/mcp/manshi-mcp.js", "--data", "/Users/USER/manshi-data"]
    }
  }
}
```

Codex CLI — در `~/.codex/config.toml`:

```toml
[mcp_servers.manshi]
command = "node"
args = ["/Users/USER/Documents/manshi-suite/mcp/manshi-mcp.js", "--data", "/Users/USER/manshi-data"]
```

Cursor و VS Code هم قالبِ مشابهِ Claude Desktop را می‌پذیرند.

**۳. ابزار را ببند و باز کن.**

---

## ابزارها

| ابزار | کار |
|---|---|
| `list_meetings` | فهرست جلسه‌ها **بدون متن**. با `only_unanalyzed` فقط بی‌صورت‌جلسه‌ها |
| `get_meeting` | یک جلسه با متن کامل |
| `list_tasks` | کارها با فیلتر وضعیت |
| `write_minutes` | صورت‌جلسه را **در صفِ تأیید** می‌گذارد |
| `inbox_status` | چند مورد منتظر تأیید است |

هر جواب `_dataFrom` دارد — تاریخِ دادهٔ فایل. بدون این، مدل نمی‌داند دادهٔ کهنه دستش
است و با اطمینان جوابِ قدیمی می‌دهد.

---

## صورت‌جلسه‌کردنِ جلسه‌های عقب‌افتاده

این کاربردِ اصلیِ پل است. در Claude Desktop یا Codex بنویس:

> ده جلسهٔ اولی که صورت‌جلسه ندارند را پیدا کن، متنشان را بخوان، برای هرکدام خلاصه و
> کارها را دربیاور و با write_minutes ثبت کن.

مدل یکی‌یکی جلو می‌رود. بعد در منشی نواری می‌آید: **«۱۰ صورت‌جلسه رسیده — بررسی کن»**.
نگاه می‌کنی، تیک می‌زنی، اعمال می‌شود.

**دسته‌دسته پیش برو.** پنجاه جلسهٔ یک‌ساعته حدود یک میلیون توکن است و به سقفِ مصرفِ
اشتراکت می‌خوری. ده‌تا ده‌تا.

---

## امنیت

- **هیچ‌چیز خودکار اعمال نمی‌شود.** `write_minutes` فقط در صف می‌گذارد.
- **جلسه‌ای که از قبل صورت‌جلسه دارد** به‌عنوان «تعارض» علامت می‌خورد و پیش‌فرض تیک نمی‌خورد.
- **`inbox.json` ورودیِ نامعتمد است** — هر برنامه‌ای روی دستگاه می‌تواند در آن پوشه
  بنویسد. منشی پاک‌سازی می‌کند: سقف طول، بررسی نوع، و ردکردنِ شناسهٔ جلسهٔ ناموجود.
- برای خاموش‌کردنِ نوشتن، سرور را با `--read-only` بالا بیاور.
- **پوشه را در دراپ‌باکس یا درایو نگذار.** با سطح «متن کامل»، `snapshot.json` حرفِ
  کلمه‌به‌کلمهٔ همهٔ جلسه‌هایت را دارد.
